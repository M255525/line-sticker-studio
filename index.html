文字模型（步驟 2「AI 依主題改寫台詞」用，選用）

跟圖像選同一家服務商時會自動共用同一把金鑰。不設定也能用：每種語言模式都內建 24 句常用台詞。

1. 主題與角色

寫一句主題，再上傳一張角色參考圖（正面、清楚、單一角色最好）。沒有圖也可以，AI 會依主題設計一隻新角色。

AI 會把主題拆成角色外觀、個性、招牌道具、口頭禪、目標族群與語氣，並依語言模式寫好台詞；有上傳參考圖時會一起分析角色外觀。完成後會自動把提示詞放進下方「產生提示詞」。

產生提示詞：貼到其他 AI 用，不花 API token

選好上面的條件後，可以把提示詞複製到 ChatGPT、Gemini、Claude 等聊天網頁版使用，不必在這裡填金鑰。建議流程：① 台詞企劃提示詞 → 把 AI 回覆貼回來匯入 → ② 生圖提示詞（會用匯入後的台詞），連同角色參考圖一起貼到 Gemini 或 ChatGPT 生圖 → 到步驟 3 上傳生好的網格圖。

3. 生成貼圖網格

每一批會生成一張「多格網格圖」，同一張圖裡的角色比較一致。分批越多，每格畫得越細，但要呼叫越多次。

4. 自動切割與匯出

依網格平均切開 → 去背 → 去除雜點 → 裁掉多餘透明邊 → 疊上台詞 → 縮放成 LINE 規格（最大 370×320、寬高偶數、留 10px 邊）。

LINE Creators Market 規格提醒

  • 貼圖張數 8／16／24／32／40 張；每張 PNG、RGB 色彩模式、72dpi 以上、最大 370×320、寬高需為偶數、單檔 1MB 以下。
  • 主要圖片 main 240×240；聊天室標籤 tab 96×74（各 1MB 以下）。背景需透明、角色四周留約 10px 空白；整包 ZIP 60MB 以下。
  • 本工具輸出時會自動寫入 72dpi，並逐檔讀回 PNG 檔頭與像素驗證；上方檢查表全部打勾才能下載 ZIP。
  • 上架前請自行確認角色與台詞沒有侵權，也符合 LINE 的審核準則。
使用警語：AI 生成的貼圖請自行確認沒有侵權、符合 LINE 審核準則後再上架；金鑰與資料只存在你的瀏覽器。
