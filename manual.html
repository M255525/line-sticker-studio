LINE 貼圖自動化助手：操作手冊

給一個主題和一張角色圖，產出 8／16／24 張符合 LINE Creators Market 規格的透明 PNG，打包成 ZIP 就能上傳。

整體流程

  1. 主題與角色：寫主題、上傳角色參考圖，挑語言模式和畫風。
  2. 台詞設定：系統依語言模式自動帶入常用台詞，可以手改，也可以讓 AI 依主題改寫。
  3. 生成貼圖：AI 一次畫一張多格「網格圖」（例如 4×3＝12 格），24 張分 2 批完成。
  4. 切割匯出：自動切格、去背、疊上台詞、縮成規格尺寸，下載 ZIP。
沒有 API 金鑰也能完整跑完：步驟 3 按「複製提示詞」，到 Gemini 或 ChatGPT 網頁版貼上，記得一起上傳角色參考圖，生好的圖再用「上傳網格圖」放回來就行。

0AI 連線設定（選用）

用途預設服務商／模型說明
圖像生成Gemini／gemini-3.1-flash-image也可以改用 OpenRouter（預設 google/gemini-3.1-flash-image，模型欄有建議清單，也能選 Gemini Pro 或 GPT 圖像模型）或 OpenAI gpt-image-1。有參考圖時會一起送出，讓每格角色長得一樣。
台詞改寫Gemini／gemini-3.5-flash也支援 OpenRouter、Claude、OpenAI。

金鑰依服務商分開保存：切換服務商不會洗掉其他家的金鑰；圖像和文字選同一家時自動共用同一把。只有一把 OpenRouter 金鑰的話，兩邊都選 OpenRouter 就好。每個金鑰欄下方都有申請連結。

金鑰只存在你自己瀏覽器的 localStorage，不會上傳到其他地方。使用的是你自己的 API 額度，生圖會產生費用。

1常用預設值

設定選項
語言模式台灣日常口語（預設）、職場上班族、長輩問候、情侶放閃、台語諧音、中英混搭、English、日本語。每種都內建 24 句，依常用程度排序；選 8 張取前 8 句，16 張取前 16 句。
畫風Q 版可愛（預設）、手繪線條、水彩、扁平插畫、像素風、厚塗。
表情誇張度自然／生動（預設）／超誇張（會加汗滴、青筋、亮晶晶等漫畫效果）。
台詞文字程式疊字（推薦）：AI 只畫角色，字由程式疊上，中文不會錯字，之後也能隨時改字。
讓 AI 直接畫字：字和畫面比較融合，但 AI 很常寫錯中文字。
不加文字：純表情貼圖。
生圖背景綠幕（推薦）最好去背；角色本身是綠色時改用洋紅；白底只會從邊緣往內去背，角色裡的白色會保留。

主題拆解（可選擇用或不用 AI）

主題欄下方的「主題拆解方式」有兩種：

  • 不使用 AI（預設）：直接用你寫的主題文字產生提示詞，不需要任何金鑰。
  • AI 拆解主題：AI 會把主題拆成角色外觀（中英文）、個性、招牌道具、口頭禪、目標族群、台詞語氣，並依語言模式寫好全部台詞（每句附動作描述）。有上傳角色參考圖時，會一起分析參考圖的外觀。

AI 拆解也有兩種做法：

  1. 🤖 AI 拆解主題：用「AI 連線設定」裡的文字模型直接拆解（Gemini／OpenRouter／Claude／OpenAI 都能看參考圖）。
  2. 複製拆解提示詞：貼到 ChatGPT、Gemini、Claude 網頁版（有參考圖就一起附上），再把回覆整段貼回「把回覆貼回這裡」→「匯入拆解結果」。不花 API token。
  • 拆解完成後，下方「產生提示詞」會自動換成拆解版的生圖提示詞：加入英文角色設計、個性與招牌道具，讓每一批的角色更一致；台詞企劃提示詞也會帶入角色設定。
  • 拆解結果的每一欄都可以直接修改，改完提示詞會立即更新；按「清除拆解」或把拆解方式切回「不使用 AI」，就會改回只用主題文字。
  • 不想讓 AI 的台詞覆蓋目前的台詞，就取消勾選「同時套用 AI 寫的台詞」。
  • 拆解後又修改主題時會提醒你重新拆解。拆解結果會跟著「儲存專案」一起存檔。

產生提示詞：貼到其他 AI 用，省 API token

步驟 1 選好條件後，下方的「產生提示詞」可以把提示詞貼到 ChatGPT、Gemini、Claude 等聊天網頁版使用，用的是你自己的聊天方案，不花 API token。

  1. 按「① 台詞企劃提示詞」→ 複製後貼到聊天 AI → 把 AI 的回覆整段貼回「把 AI 的回覆貼回這裡」→ 按「匯入台詞」。
  2. 匯入後會自動顯示「② 生圖提示詞」（每批一段），已經套用剛匯入的台詞。每段連同角色參考圖一起貼到 Gemini 或 ChatGPT 生圖。
  3. 把生好的網格圖存下來，到步驟 3 對應的批次按「上傳網格圖」，再到步驟 4 切割。
  • 提示詞長度：完整版效果比較穩；精簡版大約可以省 40～60% 的 token（台詞提示詞約 150 tokens、每批生圖提示詞約 340 tokens）。這個設定也會套用到工具內的 API 呼叫和步驟 3 的提示詞。
  • 改了任何條件，已經顯示的提示詞會自動更新，已貼上的 AI 回覆會保留。
  • 「下載全部提示詞 .txt」會把台詞提示詞、目前的台詞清單和每批生圖提示詞存成一個文字檔。
  • 沒有參考圖時，建議先生第 1 批，再把那張圖當參考圖附給後面的批次，角色才會一致。

2台詞設定

  • 「台詞」是貼圖上會出現的字；「動作／表情描述」是給圖像模型看的英文提示，可以改成更符合角色的動作（例如加上道具）。
  • 「AI 依主題改寫台詞」會依角色主題調整台詞和動作，例如上班族柴犬就會出現「打卡」「加班」類的用語。
  • 換語言模式時，台詞會重設成該模式的預設值。

3生成貼圖網格

  • 每批格數（在步驟 1 設定）：24 張預設每批 12 格（4×3，共 2 批）。每批 8 格畫得最細但要呼叫 3 次；24 格一次完成最快，但每格比較小。
  • 某一批畫得不好，可以單獨重按那一批的「AI 生成」。
  • 「下載原圖」可以把網格圖存下來，以後直接上傳重切。
  • 「產生示範網格」是用程式畫的假角色，讓你在沒有金鑰時先試試切割流程。

4切割與匯出

  • 預覽圖上的紅色虛線就是切割線。如果 AI 畫的圖外圈有留白或格子之間有間距，調整「外框內縮」「格線間距」讓虛線對準每一格。
  • 去背容差：背景沒去乾淨就調高；角色邊緣被吃掉就調低。
  • 雜點清除：會清掉從鄰格跨過來的殘影和小噪點。如果角色旁邊的小道具（愛心、汗滴）被誤刪，就把它關掉。
  • 每張貼圖下方可以直接改台詞，改完會立即重新疊字。
  • 點 ☆ 指定主要圖片，main.png（240×240）和 tab.png（96×74）會自動用那張角色產生（不含文字）。
ZIP 內容：01.png～24.png、main.png、tab.png，可以直接上傳到 LINE Creators Market。

加入主畫面（像 App 一樣開啟）

  • 電腦（Chrome／Edge）：按工具右上角「📲 加入主畫面」，或網址列右側的安裝圖示。
  • Android（Chrome）：按「📲 加入主畫面」，或瀏覽器選單 →「加到主畫面」。
  • iPhone／iPad（Safari）：點下方「分享」圖示 →「加入主畫面」。
  • Mac Safari 17 以上：選單列「檔案」→「加入 Dock」。

加入後會用獨立視窗開啟，資料、設定與金鑰跟瀏覽器版共用同一份。

專案存檔

右上角「儲存專案」會把主題、設定、台詞、參考圖和網格圖存成一個 .json 檔，「開啟專案」可以載回來繼續修改。檔案只存在你的電腦裡。

使用警語

  • 本工具協助產生台詞、提示詞與切割檔案，不保證作品能通過 LINE Creators Market 審核。
  • 角色參考圖必須是你自己創作或已取得授權的圖片；不可使用他人的版權角色、商標或真人肖像。
  • AI 生成的圖像可能與既有作品相似，上架前請自行確認沒有侵害著作權、商標權或肖像權。
  • AI 生圖的商用權利依各服務商（Google、OpenAI、OpenRouter 上的模型供應商）的使用條款而定，請自行查閱。
  • 台詞請避免歧視、暴力、色情、政治或其他違反 LINE 審核準則的內容；AI 改寫的台詞也要自己再檢查一次。
  • 按下 AI 功能時，提示詞與角色參考圖會直接送到你選擇的服務商官方 API；API 費用由你與服務商自行負擔。
  • 所有設定、圖片與金鑰只存在你的瀏覽器本機；在公用電腦使用後，請清除瀏覽器資料。
  • 規格檢查依 LINE 官方公開準則實作，LINE 若調整規格請以官方最新公告為準。
  • 本工具與創作者不對使用本工具產出的內容、上架結果或任何因此產生的損失負責。
